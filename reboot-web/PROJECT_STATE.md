## 브랜드·사업 기준에서 확인한 간극

1. 루틴 3분은 기본 피부 관리 5항목으로 모두 소진된다. 생활습관만 선택해도 피부 루틴이 나오는 것은 기존 core 정책이다. 이번에 임의로 바꾸지 않았다. 사용자 테스트로 3분 루틴의 관심사 반영 정책을 결정해야 한다.
2. D+100의 '리부트 완료'는 'STILL IN PROGRESS'의 지속성 원칙과 긴장이 있다. 명칭 결정을 후속 항목으로 남기며 기록 정책은 바꾸지 않았다.
3. 기존 설계 문서의 '배포 전', '10편', 폰트 정보가 실제 코드와 달랐다. 현재 상태로 정정했다.
4. 가이드 출처와 검수 상태를 분리해야 한다. 참고 링크 추가는 전문가 검수 완료가 아니다.
5. 기록은 브라우저 자산이다. 저장 실패를 조용히 무시하는 현재 어댑터는 재방문 신뢰에 영향을 줄 수 있어 다음 기술 우선순위다.
